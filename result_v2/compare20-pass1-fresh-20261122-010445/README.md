# 从零进化 20 轮与测试集冻结对照

运行：`compare20-pass1-fresh-20261122-010445`。北京时间 2026-11-22 01:06 开始，06:55 完成。

## 实验设置

- 固定 Qwen3-14B 权重，本地模型名 `qwen14b-local`；`embeddinggemma` 负责 state 编码。
- 从空经验库开始，20 道训练题、每题三个方案，共 60 条训练轨迹，每题仅提交一次经验更新。
- 完成后在 20 道 valid_unseen 测试题上，分别评测空经验库与冻结的最终经验库；每组 60 条轨迹。
- 每个方案均重置环境，最多 50 步；评测阶段不调用 Critic、不更新经验。
- 两组题目、环境和采样种子相同，Planner 根据各自的经验输入生成方案；方案内容不固定。
- 正式代码对应 [9530a05](https://github.com/sunshuaiqi2005-ai/Reflection_Evo_Agent/commit/9530a05508bfe2aa003d7ed2122d0fc2e8877bb1)，同时保留本次原始源码快照和文件清单。

## 完整结果

| 指标 | 空经验 | 冻结的 20 轮经验 |
| --- | ---: | ---: |
| 平均单次方案执行成功率 | 42/60，70.0% | 45/60，75.0% |
| 全部轨迹平均步数，含失败 | 29.93 | 24.22 |

训练阶段成功 39/60（65.0%），最终积累 170 条经验、60 个状态簇。平均单次方案成功率增加 5 个百分点，全部轨迹平均步数减少约 19.1%。

统计口径：原运行的 `pass_at_1.json` 将“成功轨迹数 / 60”，即每题三个方案单次执行成功率的平均，记为 pass@1。三方案任一成功的题目覆盖率另行报告；若只执行第一方案，请使用表中最后一行。当前测试只有一个主种子且场景集中，不能据此声称所有方案都稳定改善。

## 文件组织

- `report.md` / `report.json`：原始汇总报告。
- `pass_at_1.json`：原运行保存的平均单次执行指标。
- `analysis.json`：完整结果的轨迹诊断和分析。
- `episodes/`：180 条原始执行轨迹，包括 60 条训练、60 条空经验测试和 60 条冻结经验测试；包含方案、注入经验、全部动作和反馈。
- `config.yaml`、`metadata.json`、`run_info.json`：配置、模型标识和运行说明。
- `training_tasks.json`、`evaluation_tasks.json`：固定题目清单。
- `source_snapshot/`、`source_manifest.json`、`run_comparison.py`：原始源码快照及对照入口。
- `console.log`：原始控制台记录。
- `archive_info.json`：完整压缩包的 SHA-256、原始文件数及核对信息。
- `archives/`：完整原始运行目录的无损分卷归档，含全部 5180 次模型请求与响应、20 轮经验快照、逐题评测、最终经验库、向量缓存、事件记录及上述文件。共 5456 个原始文件，除 Python 字节码缓存外保持原样。

后续的提示改动、排序、经验改写和 Actor 应用说明探索不属于本归档中的完整对照结果。
